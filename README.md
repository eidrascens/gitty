# `gitty`

A personal utility built using Gtk4 and Libadwaita for committing 
files without needing to open terminal and navigating complex applications.

Note that this is for personal use; feature requests, and other issues
are within the discretion of the author.

# Contributions

All MRs are welcome. However, use PEP-008 or follow my code style that
you will see in the code.

## AI Contributions

I will accept minimal, human-guided AI-assisted contributions, but
not—and never will—AI-generated code. Use trailer `Assisted by: <LLM>`
if the code was assisted, not co-written and not generated, by LLM.
All MRs will be subjected to review, and will be accepted based on the
criterion above and its code quality.
